## Kijarney — No-Code Data Science Platform

Kijarney is a **no-code data analysis and machine learning platform** designed to make data science accessible to users without programming experience.

Users can upload datasets and perform common data-processing and analysis tasks through a graphical interface, eliminating the need to write Python or other programming code for routine data workflows.

### Key Features

* 📊 Upload and explore datasets
* 🧹 Clean and preprocess data
* 🔍 Detect missing values, duplicates, data types, and outliers
* 📈 Generate data visualizations
* 🤖 Build machine-learning models without writing code
* 📉 Support predictive analysis
* 💾 Save datasets and trained models
* ▶️ Run saved models to generate predictions
* 🖥️ User-friendly graphical interface
* 🌗 Dark and light mode

### Purpose

Kijarney aims to provide a **shortcut into data science for non-programmers**, allowing users to perform data analysis and machine-learning workflows through an easy-to-use interface.
